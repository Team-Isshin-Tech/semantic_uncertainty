SLIDE 1: TITLE & RESEARCH QUESTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Title: Robustness Analysis of Semantic Entropy Under Logit-Space Noise

Research Question:
• How does adding noise to model logits affect Semantic Entropy (SE)?
• Is SE reliable when models produce noisy/perturbed outputs?

Motivation:
• Real-world models face: quantization, temperature variations, adversarial attacks
• Need uncertainty measures that remain stable under perturbations
• SE claims to capture semantic meaning - but is it mathematically robust?

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SLIDE 2: WHY THIS RESEARCH? (Theoretical vs Empirical)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Question: "Can't we predict this theoretically?"

What We COULD Predict from Theory:
✓ Mean noise invariance (softmax cancels constant shifts)
✓ SE should remain bounded (entropy has theoretical limits)

What Theory CANNOT Tell Us:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Empirical Magnitude:
   ? How much does SE change? 1%? 50%? 500%?
   → Experiment shows: ~3% (theory doesn't predict scale)

2. Variance Structure:
   ? Is change uniform or heterogeneous across questions?
   → Discovered: 50% variance >> 3% mean (theory missed this!)

3. Non-Linear Dynamics:
   ? Does SE degrade linearly with noise, or non-linearly?
   → Found: U-shaped response (regularization → degradation)

4. Question-Level Sensitivity:
   ? Which questions are robust vs fragile?
   → Low-SE questions 5× more volatile (theory silent)

5. Realistic Noise Levels:
   ? At what σ does SE start breaking down?
   → σ ≤ 1.0 safe, σ = 2.0 begins degradation (practical threshold)

6. Semantic Clustering Behavior:
   ? Does noise blur semantic boundaries or just add randomness?
   → Small noise actually SHARPENS clusters (counterintuitive!)

Key Insight:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Theory gives QUALITATIVE predictions (invariance exists)
Experiments give QUANTITATIVE answers (magnitude, variance, thresholds)

→ We now know SE is "practically robust" not just "theoretically invariant"
→ We have actionable deployment guidelines (σ ≤ 1.0 safe)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SLIDE 3: EXPERIMENTAL SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Dataset & Model:
• TriviaQA validation set: 400 questions
• Falcon-7B-Instruct (4-bit quantized)
• 10 generations per question

Noise Model:
• Gaussian noise added to logits: logit' = logit + N(μ, σ²)
• Mean (μ): [0.0, 0.5, 1.0, 2.0] - represents bias/calibration shift
• Std (σ): [0.5, 1.0, 2.0] - represents randomness/uncertainty
• 100 noise samples per configuration

Evaluation Metric:
• Relative SE Change: ΔSE / SE_before
  - Measures percentage change in semantic entropy
  - Positive → SE increases (more uncertain)
  - Negative → SE decreases (more certain)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SLIDE 3: KEY OBSERVATION #1 - EFFECT OF MEAN NOISE (μ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[SHOW PLOT: relative_change_vs_mu_clear.png]

Observation:
┌───────────────────────────────────────┐
│  μ = 0.0  →  ΔSE = +0.00%  (±52.0%)  │
│  μ = 0.5  →  ΔSE = -0.08%  (±51.4%)  │
│  μ = 1.0  →  ΔSE = -0.08%  (±52.0%)  │
│  μ = 2.0  →  ΔSE = +0.50%  (±54.1%)  │
└───────────────────────────────────────┘

Finding: Mean noise has NO systematic effect
• All changes within ±0.5% (essentially ZERO)
• SE remains centered at 0% across all μ values
• Pattern is FLAT - no trend with increasing μ

Conclusion:
✓ Semantic Entropy is BIAS-INVARIANT
✓ Calibration shifts do NOT affect SE measurements

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SLIDE 4: WHY IS SE INVARIANT TO MEAN NOISE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Mathematical Explanation:

1. Mean noise adds constant bias to logits:
   logit'_i = logit_i + μ

2. After softmax transformation:
   p'_i = exp(logit_i + μ) / Σ exp(logit_j + μ)
        = exp(μ) · exp(logit_i) / [exp(μ) · Σ exp(logit_j)]
        = exp(logit_i) / Σ exp(logit_j)
        = p_i  [unchanged!]

3. SE depends on semantic clustering, not absolute probabilities:
   • Answers still cluster into same semantic groups
   • Clustering algorithm sees same probability rankings
   • Entropy of cluster assignments unchanged

Key Insight:
→ Adding a constant to ALL logits is like multiplying ALL probabilities
  by the same factor - relative structure preserved

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SLIDE 5: KEY OBSERVATION #2 - EFFECT OF STD NOISE (σ)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[SHOW PLOT: relative_change_vs_sigma_clear.png]

Observation:
┌────────────────────────────────────────┐
│  σ = 0.5  →  ΔSE = +2.04%  (±50.6%)   │  [SE decreased]
│  σ = 1.0  →  ΔSE = +1.09%  (±50.5%)   │  [SE decreased]
│  σ = 2.0  →  ΔSE = -2.87%  (±55.8%)   │  [SE increased]
└────────────────────────────────────────┘

Finding: Std noise shows NON-LINEAR effect
• Low noise (σ ≤ 1.0): SE slightly DECREASES (~2%)
• High noise (σ = 2.0): SE starts to INCREASE (~3%)
• Variance grows with σ: 50.6% → 55.8%

Pattern: U-shaped response
• Initially regularizing (↓ SE)
• Eventually degrading (↑ SE)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SLIDE 6: WHY DOES STD NOISE HAVE NON-LINEAR EFFECT?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Two Competing Mechanisms:

1. LOW NOISE (σ ≤ 1.0): Regularization Effect (-2% SE)
   ┌─────────────────────────────────────────────────┐
   │ Before noise:  Cluster A: [99%, 99%, 98%]      │
   │                Cluster B: [50%, 52%, 49%]      │
   │                                                 │
   │ After noise:   Cluster A: [98%, 99%, 97%]      │
   │                Cluster B: [51%, 50%, 52%]      │
   │                → Small noise smooths outliers   │
   │                → Clusters become TIGHTER        │
   │                → Entropy DECREASES              │
   └─────────────────────────────────────────────────┘

2. HIGH NOISE (σ = 2.0): Degradation Effect (+3% SE)
   ┌─────────────────────────────────────────────────┐
   │ Before noise:  Cluster A: [99%, 99%, 98%]      │
   │                Cluster B: [50%, 52%, 49%]      │
   │                                                 │
   │ After noise:   Cluster A: [70%, 95%, 85%]      │
   │                Cluster B: [60%, 30%, 75%]      │
   │                → Large noise blurs boundaries   │
   │                → Clusters OVERLAP               │
   │                → Entropy INCREASES              │
   └─────────────────────────────────────────────────┘

Conclusion: Noise level determines which mechanism dominates

  → Noise doesn't change overall semantic structure
  → SE remains stable

[SHOW BOX PLOTS with large spread]

The Hidden Story in the Data:
┌─────────────────────────────────────────────────┐
│  Average change: ±3%   ✓ Looks robust           │
│     BUT...                                      │
│  Standard deviation: ~50-56%  ⚠⚠⚠               │
└─────────────────────────────────────────────────┘

What This Means:
• Individual questions vary WILDLY: -200% to +400%
• Averaging masks heterogeneity
• Some questions gain 4× more entropy, others lose 80%

Example Breakdown:
  Question A: +0.5%   (stable)
  Question B: +250%   (explodes)
  Question C: -150%   (collapses)
  ─────────────────
  Average:    +1%     (misleading!)

Implication:
→ SE robustness is QUESTION-DEPENDENT
→ Need to identify which questions are sensitive vs stable

SLIDE 9: SUMMARY OF FINDINGS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Effect of Mean Noise (μ):
✓ NO EFFECT on SE (±0.5% change)
✓ SE is bias-invariant - only semantic structure matters
✓ Calibration shifts don't break SE

Effect of Std Noise (σ):
⚠ Non-linear relationship:
  • σ ≤ 1.0: Slight decrease (-2%) [regularization]
  • σ = 2.0: Moderate increase (+3%) [degradation]
⚠ Overall magnitude is SMALL (<3% change)
⚠ Variance increases with noise level

Question-Level Heterogeneity:
⚠ HIGH VARIANCE (~50%) dominates small mean changes
⚠ Low-SE questions: 5× more variable than high-SE questions
⚠ Individual question behavior differs dramatically

Overall Verdict:
✓ SE is REMARKABLY ROBUST on average
✓ But exhibits QUESTION-DEPENDENT sensitivity
✓ Suitable for deployment with awareness of variability

SLIDE 10: PRACTICAL IMPLICATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Where SE Can Be Reliably Used:
✓ Noisy/quantized models (SE stable under moderate noise)
✓ Temperature variations (bias-invariant property)
✓ Miscalibrated probabilities (only semantic structure matters)
✓ Applications where 3% average error is acceptable

Where Caution Is Needed:
⚠ Individual critical predictions (high question-level variance)
⚠ Extreme noise scenarios (σ >> 2.0)
⚠ Low initial SE questions (5× more volatile)
⚠ Applications requiring uniform robustness

Recommendations:
→ Use SE for aggregate/batch uncertainty estimation
→ Consider confidence intervals around SE estimates
→ Identify question characteristics that predict sensitivity
→ Combine SE with other uncertainty measures for critical cases

SLIDE 12: FUTURE WORK & LIMITATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Limitations:
• Gaussian noise assumption (real noise may differ)
• Single dataset (TriviaQA) - generalization unclear
• Question-level sensitivity not fully characterized

Future Research Directions:

1. Characterize Sensitive Questions:
   → What linguistic/semantic features predict SE volatility?
   → Can we pre-identify robust vs fragile questions?

2. Adaptive SE:
   → Develop question-specific confidence intervals
   → Weight SE by predicted robustness

3. Alternative Noise Models:
   → Heavy-tailed distributions (catastrophic errors)
   → Adversarial perturbations
   → Real-world model compression effects

4. Theoretical Analysis:
   → Why does low noise decrease SE mathematically?
   → Optimal noise level for different question types?

   • Outperforms probability-based measures
   • But requires awareness of question-level variability
