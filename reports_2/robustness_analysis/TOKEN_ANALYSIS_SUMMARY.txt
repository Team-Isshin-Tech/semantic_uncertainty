WHAT YOU CAN EXTRACT:

1. SEQUENCE PROBABILITIES:
   - Each token has its own probability (exponential of log-likelihood)
   - Sequence: how probability changes across answer tokens
   - Example: 'David' (0.85) 'Cameron' (0.12) = answer_prob = 0.85 × 0.12

2. TOKEN IMPORTANCE (Entropy Contribution):
   - High probability tokens → low entropy → certain
   - Low probability tokens → high entropy → uncertain
   - Token_Entropy = -p × log(p) shows which tokens are uncertain

3. SEQUENCE PATTERNS:
   - Decreasing probability: model confident early, uncertain later
   - Increasing probability: model uncertain early, confident later
   - Variable probability: inconsistent confidence across answer

4. ANSWER CLUSTERING BY TOKEN PATTERNS:
   - Short answers (2-3 tokens): model guesses single word confidently
   - Long answers (5+ tokens): model generates explanation, may be less confident
   - Token variance: how much confidence varies within answer
